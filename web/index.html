Keys work by position, so on a German (QWERTZ) keyboard the bottom row starts at Y; the sketch shows your letters. CV tracks have no VEL column (a gate is on or off) and play C0–B5 = 0–5.92 V, so the octave stops at 5 there. Gold arc = value stored in the song. Red arc and dot = what the module plays right now with its PERFORM macros (Main = decay / CV gate length / IN VCA decay, X = colour / glide / IN drive, Y + CV in 2 = filter). Macros are offsets and are never saved.
